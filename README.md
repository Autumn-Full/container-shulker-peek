# 容器内容预览（准星预览 · 潜影盒预览）

面向 Minecraft 基岩版的容器内容预览工具：**不打开容器即可查看其内部物品**。
提供两项预览功能，分别适用于不同场景：

| 功能 | 触发方式 | 显示位置 | 附加包版 | 服务器插件版 |
|---|---|---|---|---|
| **准星预览** | 准星对准容器方块或容器实体 | HUD 中部（按格位排布） | ✔ | ✔ |
| **潜影盒预览** | 在已打开的容器 / 背包界面中**点击潜影盒物品** | 屏幕**左缘** | — | ✔ |
| 潜影盒角标 | 满足档位判据的盒子，在其图标右下角标注内容物 | 图标右下角 | — | ✔ |
| 预览缩放（三档） | `/peek:scale` | 仅准星预览 | — | ✔ |

## 2. 单机 / 手机怎么装（`.mcaddon`）

1. 把 `.mcaddon` 传到设备上，用文件管理器**打开它** —— Minecraft 会把**行为包与资源包一起**装好；
2. 新建或编辑世界：**资源包和行为包都要启用**（缺任何一个都不会显示任何东西，也不报错）；
3. **必须打开「实验性玩法 → Beta API」**：行为包依赖 `@minecraft/server 2.1.0-beta`，不开脚本不会加载；
4. **把「视频 → GUI 缩放」设为 0**：游戏 1.21.93 有个已知缺陷（MCPE-184059），GUI 缩放非 0 时自定义字形的颜色会不对；
5. 进入世界，把准星对准容器就有了。游戏内指令需要**操作员（OP）权限**，单人世界里世界创建者默认有。

**更新**：直接导入新版本的 `.mcaddon` 覆盖安装；版本号能在资源包/行为包列表的名字末尾看到。
"怎么没变化"最常见的原因就是旧包没被替换，报告问题前先核对一下版本号。

## 3. 能看到什么

**支持的容器**：箱子、陷阱箱、木桶、潜影盒（16 种颜色）、发射器、投掷器、漏斗、合成器、箱子矿车、漏斗矿车。

**不支持的**：玩家背包、末影箱、讲台、营火（这些没有容器组件）。

显示按**格位**排列：物品在哪个槽位就画在相对的哪一格，空槽位留白 ——
小箱子 3 行、大箱子 6 行、漏斗 3 行。可选显示数量、容器中文名、位置网格、物品名等。

**潜影盒预览**（第 5 节的服务器插件版）：服务器无法感知鼠标悬停（既无数据包也无事件），
因此在容器 / 背包界面中**点击潜影盒物品**是它唯一能收到的逐格信号。点击后该盒子的内容以同样的
格位排布显示在**屏幕左缘**（界面中心被容器面板与暗幕遮挡，左缘不受影响）；转动视角、界面关闭、
或准星重新对准容器时自动收回并交还准星预览，最长显示 5 秒。位置可用
`/peek:boxpos`、`/peek:boxhspace` 单独调整。

## 4. 附加包版常用指令（需 OP 权限）

游戏内敲 `/peek:usage` 看全部。常用的几条：

| 指令 | 作用 |
|---|---|
| `/peek:display on\|off` | 预览总开关 |
| `/peek:top <数字>` | 上下位置（正数往下、**负数往上**） |
| `/peek:hspace <数字>` | 左右位置（正数右移、负数左移） |
| `/peek:gap` `/peek:lines` `/peek:perline` `/peek:width` | 行距 / 最多行数 / 每行格数 / 行宽上限 |
| `/peek:counts on\|off` | 显示数量 |
| `/peek:header on\|off` | 显示容器中文名 |
| `/peek:grid on\|off` | 按格位排版（关掉就是紧凑列表） |
| `/peek:names on\|off` | 显示物品名 |
| `/peek:slotgrid on\|off` | 显示位置网格 |
| `/peek:reach` `/peek:poll` `/peek:refresh` `/peek:resend` | 探测距离 / 轮询间隔 / 重读间隔 / 重发间隔 |
| `/peek:status` `/peek:about` | 当前取值与来源 / 项目名称、署名与防伪指纹 |
| `/peek:perf` `/peek:probe` | 性能读数 / 打印手里物品能读到哪些组件（排查用） |

参数省略即为"切换开关"。改动会写进计分板，重启世界后仍在。
（`/peek:scale`、`/peek:box`、`/peek:boxbadge`、`/peek:badgelevel`、`/peek:log` 属于**服务器版**，附加包版没有。
附加包版**只提供准星预览**：潜影盒预览、潜影盒角标与三档缩放都需要服务器插件版。）

## 5. 服务器版怎么装（BDS + LeviLamina + LegacyScriptEngine）

解压 `容器预览_服务器版_交付.zip`：包内的 **`安装手册.md`** 是权威步骤（含手工路线与各类陷阱），
**`指令速查.md`** 是完整的命令清单。概要：

1. `dist-lse/CrosshairContainerPeek/` → `<服务器>/plugins/CrosshairContainerPeek/`
2. `packs/crosshair_container_peek_icons/` → `<服务器>/resource_packs/CrosshairContainerPeekIcons/`（**目录名必须一致**）
3. 在该世界目录里登记资源包（`world_resource_packs.json` 与 `valid_known_packs.json` 两个文件）
   —— 包内 `tools/pack/sync-server-rp.mjs` 可以代劳并核对版本（需要 Node.js 18+）
4. 重启服务器；**客户端重进一次**（资源包版本变了才会重新下载，否则玩家看到的是方框）
5. 服务器**不需要**行为包，也不需要 Beta API

服务器版比附加包版**多出来**的功能：

| 功能 | 说明 |
|---|---|
| **潜影盒预览** | 在容器 / 背包界面中**点击潜影盒物品**，该盒内容显示在**屏幕左缘**；转动视角、界面关闭或准星重新对准容器时自动收回（最长 5 秒）。位置用 `/peek:boxpos`、`/peek:boxhspace` 单独调整 |
| 潜影盒角标 | 满足档位判据的盒子（四档 `/peek:badgelevel`）在图标右下角标注一张内容物小图 |
| 三档缩放 | `/peek:scale full\|three4\|half`（只影响准星预览） |
| 位置旋钮 | `/peek:top` `/peek:hspace` `/peek:boxpos` `/peek:boxhspace` |
| 屏幕自检 | `/peek:hudtest` —— 在玩家屏幕上画三行文字，用于判断"图标为什么是方框 / 问号"（再执行一次结束） |
| 服务端自检 | `/peek:check` —— 逐项验证运行链（只读，玩家亦可执行） |
| 日志开关 | `/peek:log off` —— 停止输出常规日志（开机只留一行，命令回执与错误照常） |

## 6. 常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| 完全没有预览 | 资源包没启用 / 行为包没启用 / 没开 Beta API / 准星没对着容器；服务器版还要客户端重进过 |
| 图标变成**问号或方框** | 客户端**没装或没启用资源包**（本模组的字形是私有区码点，没有字体页就画不出来）。服务器版可以让玩家敲 `/peek:hudtest` 确认；管理员可把 `server.properties` 的 `texturepack-required` 设成 `true` 强制下发 |
| 图标偏小、发虚 | 客户端用的是旧版资源包，重新导入 / 重进服务器 |
| 颜色不对 | 「视频 → GUI 缩放」不是 0（MCPE-184059） |
| 指令列表里没有 `/peek:` | 没有 OP 权限，或这个版本的自定义命令不可用（自定义命令需要 1.19.70+ 且必须开着 Beta API） |
| 位置不合适 | `/peek:top`、`/peek:hspace`（服务器版还有 `/peek:boxpos`、`/peek:boxhspace`） |
| 服务器上"手机能看到、电脑看不到" | 那台电脑没下到资源包，不是平台差异（字形页与 HUD 覆盖在所有平台是同一套机制） |
